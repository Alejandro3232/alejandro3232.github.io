# PProg Viewer

Мобильный просмотрщик текстовых конфигураций Болид PProg (PWA).

## Публикация

В репозитории уже находятся **все файлы**: `index.html`, `manifest.webmanifest`, `sw.js`, иконки и `.nojekyll`. Ничего дополнительно загружать не нужно.

Для запуска сайта один раз откройте [Settings → Pages](https://github.com/fDa1111/Pprogmobile.github.io/settings/pages) и выберите:

- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** /(root)
- Нажмите **Save**.

Адрес сайта после публикации: https://fda1111.github.io/Pprogmobile.github.io/

## Установка на iPhone

Откройте сайт через Safari. На странице нажмите «Установить на телефон», затем в Safari: «Поделиться» → «На экран Домой» → «Добавить». Работа без интернета возможна после первоначального кэширования.

## Конфиденциальность

**Не загружайте TXT-файлы с реальными конфигурациями и паролями в публичный репозиторий.** PProg Viewer читает выбранные конфигурации локально в браузере.
