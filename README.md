# PProg Viewer

Мобильный просмотрщик текстовых конфигураций Болид PProg.

## Публикация на GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Перед включением Pages загрузите из PWA ZIP-пакета все PNG-иконки и favicon.ico в корень репозитория (рядом с index.html).

Конфигурации TXT хранятся локально на устройстве: не загружайте рабочие конфигурации в публичный репозиторий.
